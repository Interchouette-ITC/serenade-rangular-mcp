## [1.0.0]

### Added

- Source-backed, embedded Serenade and Rangular documentation with browsing,
  search, section retrieval, coding guides and MCP resources.
- Rangular template diagnostics and Cargo manifest inspection.
- Stdio and Streamable HTTP transports with `serenade`, `rangular` and `all`
  profiles; local project scaffolding and Cargo tasks are limited to stdio.
- Corpus refresh and provenance checks, including Windows-safe content hashes.
- CI, coverage reporting, package verification, Docker image and release workflows.
